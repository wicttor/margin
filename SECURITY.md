# Security policy

## Reporting a vulnerability

Please don't report security issues in public issues or pull requests.

Report them privately through GitHub instead:
[Report a vulnerability](https://github.com/wicttor/margin/security/advisories/new).

Include what you found, the steps to reproduce it, and the version and OS you
used. You'll get a reply within a week. Once a fix is released, the report is
published with credit to you, unless you'd rather stay anonymous.

## Supported versions

Only the latest release gets security fixes.
